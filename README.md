# Supply Chain Demand Forecasting & Inventory Optimization

Portfolio project for demand forecasting, inventory planning, and supply-chain analytics using synthetic, non-confidential data.

## Highlights
- SKU-level demand forecasting
- Baseline, SARIMA, and gradient boosting models
- MAE, RMSE, and MAPE evaluation
- Safety stock and reorder-point recommendations
- Python, Pandas, scikit-learn, statsmodels, Matplotlib

## Run
```bash
pip install -r requirements.txt
python src/generate_data.py
python src/forecast.py
python src/inventory.py
```

## Note
This project uses synthetic data for portfolio demonstration and contains no confidential employer or customer information.
